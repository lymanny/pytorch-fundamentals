# 🔥 PyTorch Fundamentals

A beginner-friendly collection of **PyTorch lessons and practical deep learning projects**, covering essential concepts from tensor operations to CNN image classification.

## 📚 Learning Roadmap

| No. | Topic | Description |
|---|---|---|
| 01 | [Tensor](01_tensor/) | Tensor creation, operations, reshaping, and dimensions |
| 02 | [Autograd](02_autograd/) | Automatic differentiation and gradient computation |
| 03 | [Model Building](03_model_building/) | Neural network layers, activation functions, and architectures |
| 04 | [Data Pipeline](04_data_pipeline/) | Dataset, DataLoader, transforms, and TorchVision |
| 05 | [Training Loop](05_training_loop/) | Loss functions, optimizers, training, evaluation, and schedulers |
| 06 | [Saving and Logging](06_saving_logging/) | State dictionaries, checkpoints, and TensorBoard |
| 07 | [CNN Image Classification](07_cnn_image_classification/) | Practical CNN projects using MNIST and CIFAR-10 |

## 🧠 CNN Image Classification Projects

### 1. [MNIST — Handwritten Digit Classification](07_cnn_image_classification/01_mnist/)

- **Dataset:** MNIST
- **Images:** 28 × 28 (Grayscale)
- **Classes:** 10 (digits 0–9)
- **Training:** 3 epochs

### 2. [CIFAR-10 — Object Image Classification](07_cnn_image_classification/02_cifar10/)

- **Dataset:** CIFAR-10
- **Images:** 32 × 32 (RGB)
- **Classes:** 10 object categories
- **Training:** 5 epochs

## 🔄 Project Workflow

**Dataset → Model → Training → Evaluation → Prediction**
